How this page loads

One hand-written HTML file with no dependencies. The styles, the theme switch and every byte of layout travel inside the document, so the browser asks for the page, asks for a 300-byte favicon, and stops.

Markup 9.7 KB Styles 5.8 KB Script 0.7 KB
5.4 KBover the wire, gzipped
2requests, one is the favicon
0webfonts, frameworks, trackers
1render-blocking file: this one

Type is the system UI face — SF on Apple, Segoe on Windows, Roboto on Android — so nothing is downloaded to render a letter. On a 2G connection the whole page arrives in about a second.
